# Brand logo sources

All files fetched on **2026-11-28**. Images were downloaded into an isolated scratch directory, checked as real PNG/JPEG by magic bytes and decoded dimensions (Python `-I` + Pillow), then trimmed (wordmarks), downscaled to max 192 px, palette-quantised (256 colours, alpha kept) and re-encoded as PNG. Nothing downloaded was executed.

## Sources and selection rule

- **Bank list, codes, BINs:** VietQR public API `https://api.vietqr.io/v2/banks` (76 entries, fetched 2026-11-28).
- **Priority used:** (1) brand's official website, (2) official app icon on Google Play matched by package id (listing title + developer checked), (3) VietQR logo (`https://cdn.vietqr.io/img/<CODE>.png`).
- **Tier 1 (official websites) was not usable in this pass:** bank sites tested (e.g. shb.com.vn) answer automated clients with a bot-check page ("Xác minh bảo mật"), and most serve SVG/JS-rendered logos. No file here comes from tier 1.
- **Cross-check:** for every brand with a Play listing, the Play icon was compared visually with the VietQR logo. The Play icon is used (`tile`) only when it is the brand's own mark and matches VietQR (or is newer after a rebrand). When the Play icon is app-specific, seasonal or doubtful, the VietQR corporate logo is used (`wordmark`).
- **Long tail (VietQR only, not cross-checked against a second source):** banks with no verified Play package use the VietQR image. VietQR reflects the 2024-2025 renames (LPBank, BVBank, MBV, Vikki, VCBNeo), but these files were not independently verified.
